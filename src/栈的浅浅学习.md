基本类型：

真实对象（new 出来的）在堆

本质上，我在学习中也是深深的意识到在学习数据结构的时候最需要的是懂得低层代码逻辑并能手写出来，即使我知道栈的大概表述但在它的题目应用的时候也会不知如何是好，最先需要的是对栈手写的实现，Java代码如下：
```java
import java.io.*;
import java.util.*;
class MyStack {//定义一个栈类
    int top;//表示栈顶
    int[] stack;
    public MyStack(int size) {
        stack = new int[size];//创建一个数组来代表栈的空间
        top = -1;//栈顶初始化为-1
    }
    public void push(int x) {
        if (top == stack.length - 1) {//如果当前的栈已满
            int[] newStack = new int[stack.length * 2];//创建一个新的栈，容量为当前栈的两倍
            for (int i = 0; i <= top; i++) {
                newStack[i] = stack[i];//将当前栈中的元素复制到新的栈中
            }
            stack = newStack;//将新的栈赋值给当前栈
        }
        stack[++top] = x;//再把新元素压入栈
    }
    public int pop() {//pop方法用于弹出栈顶元素
        return stack[top--];
    }
    public int peek() {//获取栈顶元素，但不弹出栈
        return stack[top];
    }
    public boolean empty() {
        return top == -1;
    }
    public int size() {//获取栈中元素个数
        return top + 1;
    }
    public static void main(String[] args)throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        PrintWriter out = new PrintWriter(System.out);
        StringTokenizer st = new StringTokenizer(br.readLine());
        int n = Integer.parseInt(st.nextToken());
        MyStack stack = new MyStack(n);
        for(int i=0;i<n;i++) {
            st = new StringTokenizer(br.readLine());
            String op = st.nextToken();
            if(op.equals("push")) {
                int x = Integer.parseInt(st.nextToken());
                stack.push(x);
            } else if(op.equals("pop")) {
                if(stack.empty()) {
                    out.println("Error");
                } else {
                    out.println(stack.pop());
                }
            }
        }
        out.flush();
        br.close();
        out.close();
    }
}
```
### 栈的特点
### 引用6-12全自动仓储系统的出库质检
### 题目描述
某大型电商物流中心引进了一套全自动单通道仓储系统。该系统的货架结构非常特殊，只有一个进/出口，且内部呈纵深排列（类似于一个深井）。
货物按照订单生成的先后顺序，被赋予编号 1, 2, 3, ..., N，并依次尝试进入货架。当货物进入货架后，由于通道狭窄，后进入的货物会挡在先前的货物前面。
在进行出库质检时，机械臂只能从货架的最外侧（即最后进入的位置）抓取货物。如果机械臂需要的货物被压在内部，它必须先将外面的货物全部取出，才能拿到里面的货物。
需要注意的是，该货架的最大纵深容量为 M。也就是说，同一时间内，货架中堆放的货物数量不能超过 M 件。
现在，物流中心收到了一份特殊的出库质检清单。请你编写程序，判断在满足货架容量限制的前提下，这套系统是否能够严格按照清单上的顺序完成所有货物的出库质检。

### 输入格式
输入第一行给出 3 个不超过 1000 的正整数：M（货架容量）、N（货物总数，编号从 1 到 N）、K（待检查的出库质检清单数量）。
随后 K 行，每行给出 N 个数字的出库顺序。同行数字以空格间隔。

### 输出格式
对每一行出库顺序，如果系统能够按照该顺序完成出库，就在一行中输出 YES，否则输出 NO。

### 输入样例
5 7 5

1 2 3 4 5 6 7

3 2 1 7 5 6 4

7 6 5 4 3 2 1

5 6 4 3 7 2 1

1 7 6 5 4 3 2
### 输出样例
YES

NO

NO

YES

NO

这个题他是啥意思呢，就是这句话：如果机械臂需要的货物被压在内部，它必须先将外面的货物全部取出，才能拿到里面的货物。这就符合栈的特性，就是后进先出，先进的压在下面，在取的时候只能取后进的，考虑我的M（货物总容量），其实就是栈的最大容量，其实就是检验栈的合法性，所以代码如下：
```c++
#include <bits/stdc++.h>
using namespace std;
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(nullptr);
    int m,n,k;
    cin>>m>>n>>k;
    while(k--){
        vector<int> a(n);
        for(int i=0;i<n;i++) cin>>a[i];
        stack<int> st;
        int index=0;
        bool flag=true;
        for(int i=1;i<=n;i++){
            st.push(i);
            if(st.size()>m) flag=false;
            while(!st.empty()&&st.top()==a[index]){//就是发现我的栈顶元素等于我的要的元素，那我马上弹出来
                st.pop();
                index++;
            }
        }
        cout<<(flag&&st.empty()?"YES":"NO")<<"\n";
    }
    return 0;
}
```

其实还是要明白栈能够实现进制转换的原理在哪里，就是说我们对初始的十进制数字除以一个n，把余数纪录下来，如果商不为0，那就接着除n,知道商为0，这时把余数按出现的逆序排例起来（先出现的余数在后面，后出现的就在前面），就得到了相应的n进制数字，举个例子，以进制转二进制为例：
```
输入 35 2，运算过程如下：
35 ÷ 2 = 17 ···· 余 1
17 ÷ 2 = 8 ······余 1
8 ÷ 2 = 4 ······ 余 0
4 ÷ 2 = 2 ······ 余 0
2 ÷ 2 = 1 ······ 余 0 
1 ÷ 2 = 0 ······ 余 1
从下往上读余数：1, 0, 0, 0, 1, 1 → 二进制是 100011。
```
所以说栈就最适合来实现它，代码如下：
```java
import java.io.*;
import java.util.*;
class MyStack{//手写一个栈类
    char[] arr;
    int top = -1;
    public MyStack(int len){
        arr = new char[len];
    }
    public void push(char x) {
        if (top == arr.length - 1) {
            char[] newArr= new char[arr.length * 2];
            for (int i = 0; i <= top; i++) {
                newArr[i] = arr[i];
            }
            arr = newArr;
        }
        arr[++top] = x;
    }
    char pop(){
        return arr[top--];
    }
    boolean empty(){
        return top==-1;
    }
}
public class Main{
    public static void main(String[] args)throws IOException{
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        PrintWriter out = new PrintWriter(System.out);
        StringTokenizer st = new StringTokenizer(br.readLine());
        int m=Integer.parseInt(st.nextToken());
        int n=Integer.parseInt(st.nextToken());
        char[] table = "0123456789ABCDEF".toCharArray();//进制字符映射表
        MyStack stack=new MyStack(32);
        if (m == 0) {//特别处理为0的情况
            out.print('0');
        } else {
            while(m>0){//循环除法，将m转换为n进制数
                int rem = m%n;//和分析的逻辑一样，循环除法，每次取余，余数就是n进制数
                stack.push(table[rem]);//将余数压入栈中
                m /= n;//循环除法，每次取商
            }
        }
        while(!stack.empty()){//栈非空，则输出栈顶元素
            out.print(stack.pop());
        }
        out.flush();
        br.close();
        out.close();
    }
}
```

前面提到了我要把十进制转为一个n进制的数字，就是把这个数字num一直除以n取余数知道余数为0为止，然后倒这输出就可，在这里要把其它进制转为十进制，那我们就可以倒过来运算，就是说我们要把一个n进制的数转为10进制，那就用当前位乘n累加，正着算进行了。
比如说我把二进制转为十进制:
```
将二进制数1010转为十进制的步骤如下：
第一位 1
结果 = 0 × 2 + 1 = 1
第二位 0
结果 = 1 × 2 + 0 = 2
第三位 1
结果 = 2 × 2 + 1 = 5
第四位 0
结果 = 5 × 2 + 0 = 10
最终得出的答案就是10
```
那么可以用栈写吗，答案是肯定的，就是说利用栈先进后出的特性，先把 X 进制数每一位字符依次入栈，原本从左到右的高位到低位序列，入栈后变为栈底高位、栈顶低位；后续再逐个出栈，配合不断累乘进制基数的位权，从最低位向高位按权展开求和，就能实现 X 进制向十进制的换算。
所以代码如下：
```java
import java.io.*;
import java.util.*;
public class Main{
    public static void main(String[] args)throws IOException{
        BufferedReader br=new BufferedReader(new InputStreamReader(System.in));
        PrintWriter out=new PrintWriter(System.out);
        int x=Integer.parseInt(br.readLine().trim());
        String s=br.readLine().trim();
        Stack<Integer> st=new Stack<>();
        for(char ch:s.toCharArray()){
            int num=0;
            if(ch>='0'&&ch<='9'){//如果读到的是数字字符就直接转为数字
                num = ch - '0';
            }else{
                num = ch - 'A' + 10;//如果是字母，那就计算除字母ASCII值离'A'的距离值，再加10，因为是要转为10进制数字
            }
            st.push(num);//把数字压入栈中
        }
        long ans = 0;
        long pow = 1; //初始化为1，就是我从低位到高位要乘位数的x次方
        while(!st.isEmpty()){
            ans += st.pop() * pow;//对算出来的每一位进行加和
            pow *= x;//每升一位x就要自乘一次
        }
        out.println(ans);
        out.flush();
        out.close();
    }
}
```
而事实上我们要把m进制的数转为n进制的数时，就是把上面两个题的操作结合，即把m进制先转为十进制，再把转为的十进制数转为需要的n进制数字，所以代码如下：
```java
import java.io.*;
import java.util.*;
public class Main{
    public static void main(String[] args)throws IOException{
        BufferedReader br=new BufferedReader(new InputStreamReader(System.in));
        PrintWriter out=new PrintWriter(System.out);
        StringTokenizer input=new StringTokenizer(br.readLine());
        int m=Integer.parseInt(input.nextToken());
        int n=Integer.parseInt(input.nextToken());
        String s=input.nextToken();
        if(s.equals("0")){
            out.println(0);
            out.flush();
            br.close();
            out.close();
            return;
        }
        Stack<Integer> st=new Stack<>();
        for(char ch:s.toCharArray()){
            int num=0;
            if(ch>='0'&&ch<='9'){
                num = ch - '0';
            }else{
                num = ch - 'A' + 10;
            }
            st.push(num);
        }
        long ans = 0;
        long pow = 1;
        while(!st.isEmpty()){
            ans += st.pop() * pow;
            pow *= m;
        }
        char[] table = "0123456789ABCDEF".toCharArray();
        Stack<Character> stack=new Stack<>();
        while(ans>0){
            int rem = (int)(ans%n);
            stack.push(table[rem]);
            ans /= n;
        }
        if(stack.isEmpty()){
            out.print(0);
        }
        while(!stack.isEmpty()){
            out.print(stack.pop());
        }
        out.flush();
        br.close();
        out.close();
    }
}
```
##  ②括号非法和字符串的判断
### 引用: 牛客noob84 括号配对问题
题目链接：https://www.nowcoder.com/practice/57260c08eaa44feababd05b328b897d7?tpId=383&tqId=296645&channelPut=tracker1

这个题其实和弹栈和压栈有关，就是可以这么想，就是说我遍历字符串，发现了左扩号，那我就把他加到我们的数组里去（也就是栈里去），如果是发现了右扩号，那我就去匹配，如果说这个时候栈是空的，那就不可能是合法的，如果不是空的，那就要把栈里的元素弹出来，看他是不是左括号，如果是就是true的，否则就是false的，(总结起来就是：遇到左括号压栈。遇到右括号弹栈)所以代码如下：
```c++
#include <bits/stdc++.h>
using namespace std;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(nullptr);
    string s;
    getline(cin, s);
    stack<char> st;//利用系统的容器栈
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') {//遇到左括号
            st.push(c);//就压进去
        } else if (c == ')' || c == ']' || c == '}') {//遇到右括号
            if (st.empty()) {//如果是空就一定不合法
                cout << "false\n";
                return 0;
            }
            char top = st.top();//取栈顶元素
            st.pop();
            if ((c == ')' && top != '(') ||(c == ']' && top != '[') ||(c == '}' && top != '{')) {//进行判断
                cout << "false\n";
                return 0;
            }
        }
    }
    cout << (st.empty() ? "true" : "false") << "\n";//如果说我成双成对的取后，它空了，那就合法，否则就不合法。
    return 0;
}
```
### 引用: 牛客noob85 好串
题目链接：https://www.nowcoder.com/practice/9b072237ebdd4dd99562f01cbf594fac?tpId=383&tqId=306186&channelPut=tracker1

这个题其实要以题目为切入点，他说要用一个空串，通过加若干个"ab"来得到，那么我们就可以反着看，就是说我有一个字符串，不断找到一对ab，进行删去，看能不能删到最后把字符串删空，如果能，那他就是一个好串，如果不能，那就不是呗~~~
所以可以用栈来实现，代码如下：
```c++
#include <bits/stdc++.h>
using namespace std;
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(nullptr);
    string s;
    cin>>s;
    stack<char> st;
    for(char c:s){
        if(c=='a'){//我们遇到了a，那我压入栈
            st.push(c);
        }else if(c=='b'){//如果遇到了b，就先判断
            if(!st.empty()&&st.top()=='a'){//栈不为空而且栈里原有a
                st.pop();//那就删除，相当于删了一个"ab"
            }else{
                cout<<"Bad"<<"\n";//如果是空的那肯定就不是好串
                return 0;
            }
        }
    }
    cout<<(st.empty()?"Good":"Bad");//最好删到空了，那就是好串
    return 0;
}
```
## ③表达式的总结：
所谓表达式其实就是前中后缀表达式，前缀表达式就是说我给出一个算式运算符在数字的前面比如说：+3*4 5那就是3+4*5这种，中缀表达式就是运算符在数字间，就是（3+4)*5这样的，而后缀表达式则是就是运算符都在数字之后，比如说：3 4 5 + -就是表示3+4-5，它们的区别如下：

| 表达式类型 | 核心特点 | 括号需求 | 典型示例 |
| :--- | :--- | :--- | :--- |
| 中缀表达式 | 运算符在操作数之间，符合人类阅读习惯 | 必须用括号改变运算优先级 | 3 + 4 * 2、(3 + 4) * 2 |
| 前缀表达式（波兰表达式） | 运算符在操作数之前，无需括号即可确定运算顺序 | 完全不需要括号 | + 3 * 4 2、* + 3 4 2 |
| 后缀表达式（逆波兰表达式） | 运算符在操作数之后，栈结构即可实现解析 | 完全不需要括号 | 3 4 2 * +、3 4 + 2 * |
而事实上它们在日常中的应用特别广泛：

| 表达式类型 | 核心定位 | 核心应用场景 |
| :--- | :--- | :--- |
| 中缀表达式 | 面向人类的通用输入形式 | 日常数学书写、学术论文、计算器输入、编程语言语法、Excel 表格公式输入 |
| 前缀表达式（波兰表达式） | 面向编译器的语法解析工具 | 编译器语法分析、函数式编程语言、Lisp 系统表达式序列化、计算机代数系统、抽象语法树构建 |
| 后缀表达式（逆波兰表达式） | 面向机器的高效求值方案 | 各类计算器核心求值、Excel 公式引擎、金融量化高性能计算、工程仿真数值计算、编译器中代码生成 |

很显然，我们发现它他的数字与数字间，数字与运算符间是有隔断的，就是用了一个#号来断开，那我们一样在用栈的时候，就是说如果我遇到了数字，那就可以把它拼接起来，比如我遇到了123这个数，那我要的是100乘1+2乘10+3，所以我们在遇到一个数字num的时候，那就要有num=num*10+(当前数字字符-'0')这样就可以把数字拼接好在后面进行运算，而一旦我们遇到了#号（也就是结束符）的时候我们要把先前拼出来的数字压入栈，把num变为0，重新吸取字符拼接数字，后面如果遇到运算符的时候，就再弹出两个数字，运算得到结果再压入栈就行了，所以代码如下：
```c++
class Solution {
public:
    long long Mystack[100000010];//开出一个全局变量
    long long size = 0;
    long long legalExp(string str) {
        long long num = 0;
        for (char c : str) {
            // 数字拼接
            if (c >= '0' && c <= '9') {
                num = num * 10 + (c - '0');
            }
            // # 表示数字结束，入栈
            else if (c == '#') {
                Mystack[size++] = num;
                num = 0;
            }
            //进行运算的时候在弹出两个数字进行运算
            // 加法
            else if (c == '+') {
                long long b = Mystack[--size];
                long long a = Mystack[--size];
                Mystack[size++] = a + b;//再把运算出的结果压入栈中
            }
            // 减法（顺序绝对不能错）
            else if (c == '-') {
                long long b = Mystack[--size];
                long long a = Mystack[--size];
                Mystack[size++] = a - b;
            }
            // 乘法
            else if (c == '*') {
                long long b = Mystack[--size];
                long long a = Mystack[--size];
                Mystack[size++] = a * b;
            }
        }
        return Mystack[size - 1];//最后就弹出我们的最终结果
    }
};
```

### 6-6中缀表达式计算器
题目描述
你需要为一个简易的图形计算器编写核心逻辑。该计算器支持加法（+），减法(-)，乘法（*）和除法(/)和括号（()）。

请编写程序计算给定表达式的值。表达式保证合法，只包含非负整数、运算符和括号。

输入格式
一行字符串，表示数学表达式，长度不超过 1000。

输出格式
一个整数，表示计算结果。
输入样例
在这里给出一组输入。例如：

(2+3)*4/2-5

输出样例
在这里给出相应的输出。例如：

5

这个题其实直接弹栈压栈就特别麻烦，括号后面又有其他字符，不同运算符插在数字之间，所以在弹栈压栈的时候步骤多，繁琐，那我们想，能不能把数字和运算法分别归类，类似于上面的后缀表达式，就是用两个栈分别存数字和运算符，要运算了再弹出运算，把运算的结果压入数字栈中，不过学过四则运算的都知道，加减乘除是有先后顺序的，就是优先级，先乘除，后加减，所以我们在运算的时候要优先乘除，然后再加减，总结下来就是：
1.数字栈：存所有数字
2.运算符栈：存 + - * / (
3.遇到右括号就一直算到左括号
4.运算符按优先级自动决定谁先算
5.最后栈里剩下的就是答案
那么代码如下：
```c+
#include <iostream>
#include <stack>
#include <string>
using namespace std;
// 获取运算符优先级
int priority(char c) {
    if (c == '*' || c == '/') return 2;
    if (c == '+' || c == '-') return 1;
    return 0; // 左括号 (，表示括号的优先级最低
}
// 计算两个数 a op b
int calculate(int a, int b, char op) {
    if (op == '+') return a + b;
    if (op == '-') return a - b;
    if (op == '*') return a * b;
    if (op == '/') return a / b;
    return 0;
}
int main() {
	ios::sync_with_stdio(false);
	cin.tie(nullptr);
	cout.tie(nullptr);
    stack<int> nums;  // 数字栈（存所有数字）
    stack<char> ops;  // 运算符栈（存 + - * / ( )
    string exp;       // 表达式字符串
    getline(cin, exp);
    for (int i = 0; i < exp.size(); i++) {//这里是转后缀，其实也可以转前缀，倒过来遍历就行了
        // 处理数字
        if (isdigit(exp[i])) {
            int num = 0;
            while (i < exp.size() && isdigit(exp[i])) {
                num = num * 10 + (exp[i] - '0');//和前面一样，进行拼接数字
                i++;
            }
            nums.push(num);//当没有再遇到数字的时候，就是说可能遇到运算符了，那就停下拼接的操作，把数字压入数字栈
            i--;//抵消for循环的i++,因为这个时候它已经断了，就是前一段数字拼完了，可能遇到运算符了，就不要在移动下标了
        }
        // 左括号直接入栈
        else if (exp[i] == '(') {
            ops.push(exp[i]);
        }
        // 右括号：一直算到左括号
        else if (exp[i] == ')') {
            while (ops.top() != '(') {
            	//弹出两个数字进行运算
                int b = nums.top(); 
				nums.pop();
                int a = nums.top(); 
				nums.pop();
                char op = ops.top(); 
				ops.pop();
                nums.push(calculate(a, b, op));//再把运算结果压入栈
            }
            ops.pop(); // 弹出左括号
        }
        // 处理运算符 + - * /
        else {
        	//只要栈顶运算符的优先级 >= 当前运算符，就先算栈顶的
            while (!ops.empty() && priority(ops.top()) >= priority(exp[i])) {
                int b = nums.top(); 
				nums.pop();
                int a = nums.top(); 
				nums.pop();
                char op = ops.top(); 
				ops.pop();
                nums.push(calculate(a, b, op));
            }
            ops.push(exp[i]);
        }
    }
    // 把剩下的所有运算做完
    while (!ops.empty()) {
        int b = nums.top(); 
        nums.pop();
        int a = nums.top(); 
        nums.pop();
        char op = ops.top(); 
        ops.pop();
        nums.push(calculate(a, b, op));
    }
    cout << nums.top() << endl;
    return 0;
}
```
## ④栈和队列相互转化
实现队列其实就是普通队列和双端队列queue,那这样我们就需要两个栈来模拟队列进出，实现栈其实可以一个队列就可以了，大概如下:

用 两个栈 模拟 → 只能队尾进、队头出。
双端队列（Deque）
两端都能进、两端都能出 → 本质就是 2 个栈背对背。

用 一个队列 / 双端队列 就能模拟。
### 引用：牛客noob96 用两个栈实现队列
题目链接：https://www.nowcoder.com/practice/54275ddae22f475981afa2244dd448c6?tpId=383&tqId=23281&channelPut=tracker1

这个题我们就用一个栈来进元素，就是直接push，用一个栈来出元素，但我们的出队栈是空的，那我们就直接把入队栈的元素给他然后就输出就可，代码如下：
```c++
class Solution {
  public:
    void push(int node) {
        in.push(node);
    }
    int pop() {
        if (out.empty()) {
            while (!in.empty()) {
                out.push(in.top());
                in.pop();
            }
        }
        int ans = out.top();
        out.pop();
        return ans;
    }

  private:
    stack<int> in;
    stack<int> out;
};
```
以上实现的是普通队列的双栈实现，其实要实现双端队列，就是需要头尾都能进出，大概和上面的没太大区别，代码如下：
```c++
#include <stack>
using namespace std;
class Solution {
public:
    void push_back(int node) {
        R.push(node);
    }
    int pop_front() {
        if (L.empty()) {
            while (!R.empty()) {
                L.push(R.top());
                R.pop();
            }
        }
        int ans = L.top();
        L.pop();
        return ans;
    }
    // 队头插入
    void push_front(int node) {
        L.push(node);
    }
    // 队尾删除
    int pop_back() {
        if (R.empty()) {
            while (!L.empty()) {
                R.push(L.top());
                L.pop();
            }
        }
        int ans = R.top();
        R.pop();
        return ans;
    }
private:
    stack<int> L; // 左栈（队头）
    stack<int> R; // 右栈（队尾）
};
```

这道题有一个巨大的坑，就是他的数据范围，可到2^63左右，那这样的话long long 都会爆掉，而且会超时，其实注意到他输入的x全是整数就可以用unsigned long long把负数加到正数那一部分才是对的,而且这道题最好是用数组模拟栈来写最快，但是也可以用队列模拟，但一定要优化，比如说我队列最好开一个全局变量防止多次调用，而且在使用前要清空原队列让他防止调用多次，用双队列进行我们的优化等等
代码如下：
```c++
#include <bits/stdc++.h>
using namespace std;
typedef unsigned long long ll;
queue<ll> q1, q2;//利用双队列模拟栈：q1作为主存储队列，q2临时中转元素
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(nullptr);
    int T;
    cin>>T;
    while (T--) {
    	//每组用例开始前清空两个队列，复用全局容器，避免反复创建销毁容器增加时间消耗
        while (!q1.empty()) q1.pop();
        while (!q2.empty()) q2.pop();
        int n;
        cin >> n;
        while (n--) {
            string op;
            cin >> op;
            if (op == "push") {//如果输入push就加入x
                ll x;
                cin >> x;
                q1.push(x);
            } else if (op == "pop") {//如果输入pop就需要判空
                if (q1.empty()) {
                    cout << "Empty\n";
                } else {
                    while (q1.size() > 1) {
                    	//把q1除栈顶元素的外全部元素挪入中转队列q2
                        q2.push(q1.front());
                        q1.pop();
                    }
                    //q1仅剩栈顶元素，弹出即完成出栈，就是说每次就只要般一个元素了，时间消耗大大减小
                    q1.pop();
                    //其实就是让q2临时存一下元素，再把元素交换回来
                    swap(q1, q2);//swap交换地址，交换速度快
                }
                //和pop是一样的逻辑
            } else if (op == "query") {
                if (q1.empty()) {
                    cout << "Anguei!\n";
                } else {
                    while (q1.size() > 1) {
                        q2.push(q1.front());
                        q1.pop();
                    }
                    //取了栈顶元素后
                    cout << q1.front() << "\n";
                    //再把它放回中转队列，符合题目的只查不删的要求
                    q2.push(q1.front());
                    q1.pop();
                    //再把它交换回来
                    swap(q1, q2);
                }
            } else if (op == "size") {
                cout << q1.size() << "\n";
            }
        }
    }
    return 0;
}
```
